# 🍽️ Meal Recipes App

An Android application built with Kotlin that provides users with a comprehensive recipe management and discovery platform. Browse, search, and discover delicious meal recipes with detailed cooking instructions and ingredients.

## ✨ Features

- **Browse Recipes**: Discover a wide variety of meal recipes from different cuisines
- **Search Functionality**: Find recipes by name, ingredients, or cuisine type
- **Detailed Recipe Information**: View comprehensive details including ingredients, measurements, and step-by-step instructions
- **Recipe Categories**: Browse recipes organized by meal categories
- **Favorites/Bookmarks**: Save your favorite recipes for quick access
- **Responsive UI**: Beautiful and intuitive user interface optimized for all screen sizes
- **Offline Support**: Cache recipes for offline viewing
- **Recipe Filters**: Filter recipes by dietary preferences, cooking time, and difficulty level

## 📱 Project Overview

The Meal Recipes App is a feature-rich Android application designed to help food enthusiasts discover and learn new recipes. Whether you're a beginner cook or an experienced chef, this app provides an easy way to explore culinary creations with detailed instructions and ingredient lists.

### Key Highlights:
- Built entirely in **Kotlin** for modern Android development
- Uses **MVVM architecture** for clean code separation
- Integrates with **TheMealDB API** for comprehensive recipe data
- Implements **Room Database** for local data persistence

## 🛠️ Tech Stack

### Frontend
- **Language**: Kotlin
- **UI Framework**: Android Native (XML Layouts)
- **Architecture**: MVVM (Model-View-ViewModel)

### Libraries & Frameworks
- **AndroidX**: Core compatibility libraries
- **Jetpack Components**:
  - LiveData
  - ViewModel
  - Room (Database)
  - Navigation Component
- **Networking**: Retrofit2, OkHttp
- **Image Loading**: Glide
- **Coroutines**: For asynchronous operations

### Backend/API
- **TheMealDB API**: Comprehensive meal and recipe database

### Development Tools
- **Build System**: Gradle
- **Version Control**: Git
- **Target SDK**: Android 13+ (API Level 33+)
